# pbdb2-migrations
Migration scripts for PBDB2

Note: The scripts in this repo are currently experimental attempts to use Claude Code for this task. They are not canon until this comment is removed.

Note: The files in the mariadb, postgresql, and payloadSchemas directories are copied from the pbdb2-dev repo. This was for convenience in setting up Claude context. They must be kept in sync with that repo or the context must be expanded to include that repo.
